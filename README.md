This is a Bar Application designed to help bartenders and bar managers easily keep track of alcohol inventory and restock items when needed.

Features
Browse different categories of alcohol and spirits (Whiskey, Vodka, Tequila, Gin, Rum, Beers & Seltzers, Wines).
Add products to a shopping cart with quantity control.
Remove items or clear the entire cart.
Displays total items and cost in real time.

How to Use
Start the app.
Browse through the alcohol categories.
Add items to your cart using the "+" button.
Adjust quantities or remove items from the cart.
View total cost and items.
Navigate using the category buttons to shop other products.

To get started , make sure you open your IDE of choice
Make sure you have node.js installed

On your terminal, go the project folder
cd Capstone_BarApp
npm install
npm start
Once npm start runs , the application will open in the browser , if not please click below
http://localhost:3000

To exit the application, using the keys below , this will shutdown the server
Ctrl + C
, Command + C (on Mac)
